# Формат отчёта

Применяй только при аудите/регрессии; при кратком ТЗ не раздувай отчёт.

## [Название темы], [класс] — итог

**Проверенная версия:** URL/ветка/коммит/дата, если известно. **Режим:** аудит/регрессия/ТЗ.

**Вердикт:** 2–3 предложения: готовность для урока и главные риски.

## Находки по приоритету

| Приоритет | Статус проверки | Где | Проблема и влияние | Что изменить | Приёмка |
|---|---|---|---|---|---|
| P1 | Проверено / по коду / гипотеза | точное место | ... | ... | ... |

Отделяй ошибки от дополнительных идей.

## Идеи, которые реально улучшат обучение

Для каждой: учебная проблема → интерактивная модель → действия ученика → математический эффект → 1–3 проверяемых критерия. Не предлагай «ещё 100 вопросов» вместо объяснения.

## User Stories / ТЗ

Для 1–3 приоритетных изменений — по [шаблону](user-stories.md).

## Проверки

**Сделано:** код/загрузка/клики/мобильные размеры/случайные задачи/статический скрипт — перечислять только действительно сделанное.

**Не сделано:** честно указать недоступное.

**Порядок исправлений:** P0 → P1 → P2 → P3. Не начинать с цвета, пока неверны рисунки или решения.
