# ТЗ и User Stories: рабочий формат

## Структура

**Название изменения:** по существу, без рекламных формулировок.
**Цель обучения:** какое понятие ребёнок должен понять или действие освоить.
**User Story:** «Как ученик N класса, я хочу [действие] для того, чтобы [учебный результат]».
**Сейчас:** наблюдаемая проблема, подтверждённая кодом/браузером, или гипотеза.
**Нужно:** конкретная логика интерфейса, визуального объекта и математических правил.
**Пример:** один реальный вход и математически проверенный ожидаемый результат.
**Состояния:** первая загрузка, правильный ввод, ошибка, подсказка, переключение, перезагрузка.
**Не включаем:** что сознательно остаётся без изменений.
**Критерии приёмки:** наблюдаемые и проверяемые условия, а не «красиво», «понятно», «без багов».
**Приоритет:** P0–P3, с объяснением.

## Пример: сравнение дробей

**Цель:** понять сравнение дробей через положение на общей числовой прямой.

**User Story:** «Как ученик 5 класса, я хочу видеть две заданные дроби на одной числовой прямой, чтобы обосновывать, какая больше, по их положению».

**Нужно:** ввод двух допустимых дробей; разметка прямой с нулём и единицей; деления согласованы с обоими знаменателями; точки подписаны; при равенстве дробей точки совпадают; неправильные дроби не обрезаются.

**Пример:** 3/4 правее 2/3; 2/4 и 1/2 совпадают; 5/4 правее 1.

**Приёмка:**
1. Точки для 3/4 и 2/3 стоят в координатах 0.75 и ~0.667; первая правее.
2. 2/4 и 1/2 обозначают одну точку и показывают равенство.
3. 5/4 отображается правее единицы; масштаб расширяется корректно.
4. Нулевой знаменатель отклоняется до построения, а не приводит к сломанному рисунку.
5. После смены числа подписи, деления, точки и вердикт обновляются согласованно.

## Пример: признаки равенства треугольников

**Цель:** научиться устанавливать достаточность данных, а не узнавать рисунок по расположению.

**User Story:** «Как ученик 7 класса, я хочу определить по отметкам на двух чертежах, можно ли доказать равенство треугольников, и назвать признак».

**Нужно:** часть случаев действительно достаточна, часть нет; отметки располагаются только на данных из условия; треугольники повёрнуты/масштабированы так, чтобы не подсказывать ответ внешним видом.

**Приёмка:** каждый рисунок отдельно проверен по известным данным; SSA («две стороны и не заключённый между ними угол») не выдан автоматически за признак; ответ содержит точное математическое обоснование.
