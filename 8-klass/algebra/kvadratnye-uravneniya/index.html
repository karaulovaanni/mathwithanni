Коэффициенты

ax² + bx + c = 0

Читаем: «а икс в квадрате плюс бэ икс плюс цэ равно нулю».
Квадратное уравнение: a ≠ 0. Решаем в действительных числах.

Нажми на подпись — найди её цвет в уравнении.

Читаем конкретное уравнение

2x² − 5x + 3 = 0
a = 2b = −5c = 3

Знак относится к коэффициенту: b = −5, а не 5.

Единицу не написали — коэффициент всё равно есть

−x² + 4x = 0
a = −1b = 4c = 0

Нет свободного члена — значит c = 0.

Виды уравнений

Полное: все три слагаемых на месте

a ≠ 0, b ≠ 0, c ≠ 0.

Неполное: b = 0 или c = 0

Может отсутствовать член с x, свободный член или оба сразу.

Приведённое: a = 1

«Приведённое» — про a. «Полное/неполное» — про b и c. Уравнение может быть приведённым и неполным одновременно.

Как сделать уравнение приведённым

Обе части делим на 2

Делим каждое слагаемое. Корни уравнения сохраняются.

Пример: собираем формулу по цветам

2x² − 5x − 3 = 0
a = 2b = −5c = −3

В числителе −b = −(−5) = 5; в знаменателе 2a = 4.

Корни — точки пересечения с осью Ox

Два пересечения → два корня. Касание → один. Нет пересечений → нет действительных корней.
