Квадратное уравнение и его коэффициенты

Квадратное уравнение — уравнение вида ax² + bx + c = 0, где a, b, c — действительные числа и a ≠ 0.

Как читать запись

a — старший коэффициент;
b — второй коэффициент;
c — свободный член.

В уравнении −x² + 5x − 6 = 0: a = −1, b = 5, c = −6. Знаки относятся к коэффициентам.

Полное, неполное, приведённое

Полное: b ≠ 0 и c ≠ 0.
Неполное: b = 0 или c = 0.
Приведённое: a = 1.

Если a = 0, уравнение уже не квадратное.

Перед определением коэффициентов раскрой скобки, перенеси все члены влево и приведи подобные. Справа должен остаться ноль.

Неполные уравнения: три случая

1. ax² = 0

Поскольку a ≠ 0, делим обе части на a. Получаем x² = 0, значит x = 0.

2. ax² + c = 0

Обозначим правую часть k. При k > 0: x = ±√k. При k = 0: x = 0. При k < 0: действительных корней нет.

Ответ: √5 и −√5.

Действительных корней нет.

3. ax² + bx = 0

x = 0
или
ax + b = 0

Произведение равно нулю тогда и только тогда, когда хотя бы один множитель равен нулю.

2x = 0 или 2x + 5 = 0. Ответ: 0 и −5/2.

Не дели на x: так теряется возможный корень x = 0.

Почему у x² = k два решения?

График функции y = x² — парабола. Вершина находится в начале координат, ветви направлены вверх, ось симметрии — ось Oy. Область определения: все действительные числа; значения y неотрицательны.

Чтобы решить x² = k графически, проведи горизонтальную прямую y = k. Абсциссы точек пересечения — корни уравнения. При k > 0 точки симметричны: −√k и √k. При k = 0 прямая касается вершины, при k < 0 пересечений нет.

Например, √25 = 5 — одно значение арифметического корня, а уравнение x² = 25 имеет два корня: −5 и 5.

Если в квадрате целая скобка

Получаем две возможности: x − 2 = 3 или x − 2 = −3. Поэтому x = 5 или x = −1. Раскрывать скобки здесь необязательно.

Выделение квадрата двучлена

Этот способ объясняет происхождение формулы корней: превращаем левую часть в квадрат выражения.

x − 3 = 4
x = 7
или
x − 3 = −4
x = −1

Прибавили 9 к обеим частям, а не только слева. Проверка: 49 − 42 − 7 = 0; 1 + 6 − 7 = 0.

Переход к общей формуле

Такое равенство получается после деления ax² + bx + c = 0 на a и выделения квадрата. Знаменатель 4a² положителен, поэтому число решений зависит от знака b² − 4ac.

Дискриминант и формула корней

Главные формулы

Формулы корней применяем при D ≥ 0. Число 2a делит весь числитель.

D > 0

Два различных корня.

D = 0

Один корень x = −b/(2a).

D < 0

Действительных корней нет.

Корни — пересечения с осью Ox

Меняй c в уравнении x² − 4x + c = 0. Вершина движется, число пересечений меняется.

Алгоритм решения

  1. Приведи уравнение к стандартному виду.
  2. Выпиши a, b, c вместе со знаками.
  3. Вычисли D и сравни его с нулём.
  4. Если D ≥ 0, подставь числа в формулу корней.
  5. Упрости корни и дроби. Проверь подстановкой.

Два корня

Ответ: 3 и −1/2. Проверка второго: 2 · 1/4 + 5/2 − 3 = 0.

Один корень

Ответ: 5. Также можно заметить (x − 5)² = 0.

Действительных корней нет

Из отрицательного числа действительный квадратный корень не извлекается. Решение завершено.

Скобки, дроби и текстовые задачи

Сначала упрощаем, потом выбираем способ

Теперь применяем разложение (x + 3)(x − 2) = 0 или формулу корней.

Умножим обе части на 2: x² − 6x − 1 = 0. Числовые знаменатели не создают ограничений на x.

От условия — к уравнению

Прямоугольник на 5 см длиннее своей ширины, его площадь 84 см².

x + 5
Площадь 84
ширина x

Ширина x > 0, длина x + 5. Составим x(x + 5) = 84, то есть x² + 5x − 84 = 0. Корни 7 и −12. Отрицательное значение не подходит по смыслу задачи.

Ответ: ширина 7 см, длина 12 см.

Проверяем себя

  • Не теряй знак коэффициента b.
  • В знаменателе формулы стоит 2a, а не 2.
  • При D = 0 один различный корень; при D < 0 действительных корней нет.
  • Не дели на выражение с неизвестным без проверки его нулей.
  • Подбор по Виету должен учитывать и сумму, и произведение.
  • После раскрытия скобок уравнение может стать линейным или тождеством. Сначала приведи подобные.
