# Квадратный корень · 8 класс

Страница обновлена по структуре `5-klass/matematika/drobi-master`: вкладки тем, теория, SVG-модель, практика по мини-темам и уровням, светлые карточки заданий для тетради, повторение «Всё ли усвоено?».

Темы: смысл и область допустимых значений; свойства произведения и частного; степени, знаки и модуль; внесение/вынесение множителя; действия с корнями; формулы сокращённого умножения; дроби с корнями; числовая прямая; линейные уравнения; y=x² и x²=a; неполные квадратные уравнения. Полные квадратные уравнения не вводятся.

- `math.js`: разбор арифметической записи, MathML и проверка эквивалентных ответов без eval.
- `lesson-data.js`: теория, 176 онлайн-заданий и карточки для тетради. Раздел неполных уравнений опирается на первый и второй уровни пользовательского сборника.
- `lesson.js`: вкладки, тренажёры, числовая прямая, SVG-модели.
- `legacy.js`: сохранённая практика из прежней версии страницы.
- `lesson.css`: самостоятельные стили в общей палитре сайта.

Онлайн-проверка сообщает только верность ответа; готовые ответы к упражнениям не раскрываются. Разобранные примеры относятся к теории. Черновик подключён из общих assets. Введённые ответы живут в памяти вкладки; при обновлении страницы сбрасываются.

Старые ссылки `#s1`–`#s5` направляются в соответствующие темы. Корневой `kvadratny-koren.html` продолжает перенаправлять на эту страницу.
