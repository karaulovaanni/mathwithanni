# Матемастерская Аньки

Учебные занятия и интерактивные тренажёры по математике.

## Структура

- `index.html` — главная страница и каталог всех занятий.
- `3-klass/matematika/` — занятия и тренажёры 3 класса.
- `5-klass/matematika/` — темы математики 5 класса.
- `5-klass/geometriya/` — геометрия 5 класса.
- `8-klass/algebra/` — алгебра 8 класса.
- `trenazhery/` — общие тренажёры без привязки к одному классу.
- `assets/` — PDF и изображения.
- `favicon*`, `apple-touch-icon.png` — общие иконки сайта.

У каждого занятия своя папка со стартовой страницей `index.html`.
Скрипты, используемые только одним занятием, хранятся рядом с ним.
Имена папок и файлов: латиница, строчные буквы, слова через дефис.

HTML-файлы в корне, кроме главной, оставлены для перенаправления со старых адресов.
Они сохраняют параметры ссылки и номер раздела после `#`.
Новые ссылки следует направлять сразу на страницы в папках.

При добавлении темы создайте папку занятия, добавьте карточку на главную
и проверьте относительные пути к главной, материалам и иконкам.
