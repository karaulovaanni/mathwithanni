# Матемастерская Аньки

Статический сайт на GitHub Pages. Главная — index.html.

## Структура

- 3-klass/matematika/ — занятия 3 класса.
- 5-klass/matematika/ — занятия 5 класса; drobi-master — единственный урок дробей.
- 5-klass/geometriya/ — геометрия 5 класса.
- 6-klass/matematika/ — проценты и дробь от числа.
- 8-klass/algebra/ — квадратный корень.
- trenazhery/ — общие тренажёры.
- assets/ — общие стили, скрипты и изображения.
- assets/previews/ — сжатые первые страницы PDF.

Уроки хранятся в папках со своим index.html. Скрипты конкретного урока лежат рядом.
HTML в корне, кроме index.html, — короткие перенаправления со старых опубликованных адресов.
Они сохраняют параметры и раздел после #; содержимое уроков не дублируют.
Новые ссылки направляются сразу в папки.

## Библиотека

PDF хранятся в Google Drive: https://drive.google.com/drive/folders/1mKXAUQ5TAVxbTkF5vD3fcwvK_U__Ygai
В репозитории остаются только первые страницы WebP; доступ к оригиналам определяется настройками Google Drive.
Карточки и постоянные ссылки находятся в index.html.
Новый PDF: загрузить в папку Drive, сделать сжатое превью, добавить карточку.
Список на сайте обновляется вручную; ключи и токены Google в сайт не встраиваются.

## Навигация

assets/catalog.js сохраняет открытые классы и прокрутку для возврата из уроков в этой вкладке.
Обновление главной сбрасывает раскрытые классы.
