Подобные слагаемые

Одна буква — одна группа

Памятка и образец

Подобные слагаемые имеют одинаковую буквенную часть.

Сложи или вычти их коэффициенты (числа перед буквами).

Буквы a и b различны: слагаемые с ними собираем отдельно.

Образец: 5a + 3b + 2a + b + 4 = 7a + 4b + 4

Помни: x = 1x. Обычные числа объединяем отдельно.

Уравнения: умножение и деление

Идём от последнего действия к первому

Памятка и образец

Определи последнее действие с выражением, содержащим x.

Найди неизвестный компонент; затем повтори шаг внутри скобок.

(x + 8) · 3 = 60 → x + 8 = 60 : 3 → x = 20 − 8 = 12

72 : (x + 3) = 8 → x + 3 = 72 : 8 → x = 9 − 3 = 6

Проверка: подставь ответ в исходное уравнение.

Уравнения: смешанная практика

Скобки, подобные и обратные действия

Памятка и образец

Если есть подобные слагаемые, сначала упрости выражение.

Затем находи неизвестные компоненты по шагам.

(3x + 2x + 10) : 5 = 8 → (5x + 10) : 5 = 8

5x + 10 = 40 → 5x = 30 → x = 6

Неизвестный множитель = произведение : известный множитель.

Уравнения: все действия

Повышенный уровень · решай по шагам

Памятка и образец

Сложное выражение в скобках можно считать одним числом.

Внешние действия «снимаем» в обратном порядке.

((x + 6) · 4 − 8) : 2 = 20 → (x + 6) · 4 − 8 = 40

(x + 6) · 4 = 48 → x + 6 = 12 → x = 6

Делить на ноль нельзя. Обязательно выполни проверку.
