# Доли и дроби — отдельный дубль

Новая первая подтема находится в index.html, style.css и app.js. MagicPath и внешние библиотеки не используются. Прогресс не сохраняется.

materials/ — независимая копия прежних материалов остальных подтем. Нынешняя страница doli-i-drobi не меняется. Ссылки внутри копии используют её собственные скрипты и пиццерию.

Чтобы убрать дубль, удалить папку drobi-master и его отдельную карточку из корневого index.html. Основной урок продолжит работать.
